    ⚠ 加载压力场景会清空当前世界（几百个刚体没法叠加到现有世界上）。 按钮上会写明将生成多少个物体、手机端会降级到多少。

    模板生成（M4 第 3 批）

    从 8 套模板里选一套，用 9 阶段流水线生成新地图：高度图 → 水 → 沙 → 地表材质 → 自然物 → 建筑规划 → 建筑 → 小物品 → 全量冲突检测与修复。 树不会被土盖、建筑不重叠不悬空、小物品不堵门都由最后那个阶段保证。

    选一套模板 → 先「预览」看近似地形 → 再「生成」。预览是降采样近似，不是真实体素。

    打开后会把最近一次生成的冲突画成彩框：红=重叠 黄=悬空 橙=越界 紫=被埋 蓝=挡门。 框的边长是按严重度放大的标记，不是真实相交体积（相交尺寸只在日志文字里）。
